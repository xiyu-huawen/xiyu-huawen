# 锡语华纹 1.3：知识、创作与资产的循环

## 已落地的使用路径

阅读有出处的文章 → 选择来源纹样 → 在器物上设计 → 以作品为底稿或空白绘制 → 编辑笔画 → 确认使用权并入库 → 再次入器、继续编辑或派生新版本。

共创工坊支持自由画笔、花瓣/圆/方形、1/2/4/6/8向与镜像、选取拖动、缩放旋转、线宽填色、复制删除、撤销重做，以及SVG和透明PNG导出。当前作品可直接作为底稿；底稿保留原貌，新增笔画可以编辑。

入库资产具有独立编号、矢量版本、可编辑配方、底稿设计/父作品编号、原始图元引用及知识参考快照。再次编辑发布产生新资产，旧资产保持不变。传统档案与当代创作分开标识与检索，不把作者表达当成已经确认的传统寓意。

## 交互与布局

3D视口、操作栏、来源解释、方向卡和图元编辑器分区排布。默认缓慢环视；手动拖动时暂停，松开1.5秒后恢复；用户主动暂停和系统减少动态设置受到尊重。

相同的“莲心清正＋笔筒＋进阶编辑”场景，已在1440、1800宽屏及390px手机检查，视口、来源、工具栏和说明无相交、无横向溢出。

## 入库质量与保存

SVG禁止脚本、外链、外部实体与不受支持的元素；开放笔画按实际线宽形成可复用闭合轮廓。正确处理nonzero/evenodd填充规则，分别保留彩色原作与金属轮廓；源SVG与复用结果不会因简单异或产生额外孔洞。复杂度、记录容量与坐标受到限制。

已入库的新作、编辑配方、来源谱系及原图/轮廓文件保存在SQLite和/data/assets中。完整数据卷必须一起备份。本机草稿为便利功能；空间不足会明确提示先入库，不能把未发布草稿当成可靠的数据备份。

这是项目共享空间，尚无独立用户账户和私人作品权限。使用权由提交者确认；平台的技术检查不等于权属、文化释义或加工认证。

## 验证与交付

ARM64、AMD64各20项测试通过，AMD64使用模拟运行。两种架构均完成干净数据卷启动、重启持久化、停止写入后备份和独立卷恢复；包含新资产、编辑配方、谱系及SVG文件。

部署版实际走通了“威海锡镶文章→带出处设计→底稿上新增四向花瓣→入库→再次入器→工程包下载”，并保留一份名为“锡光续纹”的实际当代创作。

当前交付包在outputs/1.3.0。运行实证的资产JSON/SVG为可审阅快照，不是自动恢复整个项目的数据库备份。AI出图、工厂设备导入和实物打样仍沿用此前未验证边界，视觉与资产能力升级不改变这些条件。
