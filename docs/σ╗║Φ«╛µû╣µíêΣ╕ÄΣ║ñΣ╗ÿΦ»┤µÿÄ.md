# 锡语华纹 · 展示演示平台

基于60篇现有Word纹样标注文档，建设“查纹样—懂寓意—生成设计—器物预览—查看依据—下载成果”的浏览器体验。页面采用参考图的米白纸面、墨绿、朱红印记与宋体标题；器物为Three.js程序化模型，运行无需外部素材服务。

## 已实现

- 首页、名称及场景筛选、纹样详情、原图与基因拆解、意象及权重证据、原文查看。
- 基于已确认映射的自然语言匹配，中心／环带／连续构图，换样本、跨样本四叶莲心替换、数量／缩放／间距／颜色调整。
- 紫砂壶、茶承、书签的旋转缩放与同步纹样效果；器型／平面切换，SVG与PNG下载、收藏恢复、设计编号链接。
- 密码保护的管理接口与文档上传、重处理、任务刷新、冲突和异常记录。
- 默认规则生成，外部兼容OpenAI的模型仅辅助意图理解，未配置或失败时回退规则。AI密钥仅在服务端。

## 数据与边界

本轮解析60篇，238个独立编码，402条基因出现记录，145份图元矢量出现记录。独立编码数不等于已消解的文化实体数：31条同码异名记录保留为冲突，没有盲目合并；所有图元仍以“样本＋编码＋版本”调用。IMG与REL编号加样本命名空间。

PAT-038、PAT-040当前图元未通过前景比例检查，可浏览原图但不可生成；其他58篇可进入组合。自动矢量不等于人工精修或生产认证。候选关系明确提示，不用于确定语义解释。当前采用简化贴附预览，不提供真实浮雕、器面展开、生产刀模、工艺校验或订单。

意象解释只引用所选样本中已确认且涉及调用图元的映射证据。生成时保存SVG快照、图元及来源、原文版本、配方与随机种子，后续修改资料不改变已保存导出结果。

收藏为当前演示实例共享记录，没有用户账户隔离。演示部署不应收集个人信息；正式多用户运营需增加认证、授权与限流。后台管理员可更新资料；20MB上传限制、100MB解压限制与XML安全解析已启用。

## 实施结构

Vue 3 / TypeScript / SVG / Three.js前端；FastAPI / SQLite后端；Pillow去底、VTracer轮廓追踪、CairoSVG输出PNG。SQLite及上传资产存放持久卷，预解析资料封装在镜像中。

原始资料在`原始内容`，解析结果在`seed/catalog.json`与`seed/assets`，异常清单在`seed/quality-report.json`。保留文档名、表格行列、图片哈希与原文。CMYK只标注为屏幕近似色。

## 后续生产阶段

与工坊确认器物尺寸、线宽、镂空强度、焊点、曲面适配和设备参数后，另行建设DFM、审核、DXF与制造工程包。500篇纹样、2000基因为后续数据目标，不作为当前成果展示。

## 第二版：从生成工具到文化体验

根据反馈，放开原参考页面布局，改以“展陈—阅读—探索—造物”组织体验。

- 展陈：首页采用深墨、旧金与纸色，实时器物、轨道纹线、拱形藏品展架与可选祝福签。
- 书房：7篇基于现有资料的文章，8个术语、5段工艺路径、读纹问答及带出处的阅读弹窗。
- 可视化：基因—意象关系图、映射证据卡、同构图跨样本关系图、图元逐步阅读、四种构图的参数实验。
- 造物：主纹／环饰／点缀分别选配，可搜索真实图元，调整旋转、数量、间距、尺寸与颜色。新组合保留各自来源，不继承未经证实的整体寓意。
- 器物：三维几何凸起、器面贴附、环境光影、紫砂／墨陶／素瓷、素锡／亮锡／暖金视觉饰面、拆解与热点讲解。暖金仅为视觉表达，不代表本项目已经具备对应材料工艺。
- 解释：需求—意象—纹样的推荐路径、逐条依据和文化边界分开展示；导出JSON设计档案包含参数、来源与SVG快照。

新增接口配方字段`layers`（pattern_id、code、role），`rotation`、`width_mm`、`height_mm`；导出格式增加`json`。均经过服务端白名单与范围校验。
