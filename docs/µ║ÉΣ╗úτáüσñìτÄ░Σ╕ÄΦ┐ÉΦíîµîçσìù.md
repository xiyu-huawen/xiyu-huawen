## 一、 赛事复现总览与依赖环境清单

为了保障赛事评审专家能够顺利、客观、便捷地复现并检验「锡语华纹」项目的完整功能，系统提供了多种复现模式。评审方可根据本地机器环境选择最适宜的方式：

### 1.1 必须的基础环境依赖（根据运行模式任选其一）

#### 模式 A：Docker 容器化全栈复现（强烈推荐，环境隔离、零污染、开箱即用）
- **容器引擎**：Docker Engine 24.0+ 或 Docker Desktop 4.20+
- **编排工具**：Docker Compose v2（终端支持 `docker compose` 命令）
- **支持架构与系统**：
  - Apple Silicon Mac（M1/M2/M3/M4 系列芯片，ARM64 原生支持）
  - 通用 Linux 服务器 / PC（x86_64 / AMD64 原生支持）
  - Windows 11 专业版（通过 WSL2 运行 Docker Desktop）
- **推荐硬件配置**：CPU 2 核及以上，物理内存 >= 4 GB（推荐 8 GB），磁盘空闲空间 >= 10 GB
- **网络端口**：宿主机默认占用 `8088` 端口（若有冲突，可在 `.env` 中自由修改为其他端口）

#### 模式 B：本地物理机源码分端运行（深度代码审计与二次开发）
- **后端运行环境**：
  - **Python 运行时**：Python 3.11+（建议使用 3.11 或 3.12）
  - **系统级底层图形库（必须安装）**：`libcairo2`（用于 Cairo 矢量图形渲染与 SVG 转 PNG）
    - *Debian / Ubuntu*：`sudo apt-get update && sudo apt-get install -y libcairo2 libcairo2-dev`
    - *macOS*：`brew install cairo`
    - *CentOS / RHEL*：`sudo yum install -y cairo cairo-devel`
  - **Python 核心依赖包**：通过 `backend/requirements.lock` 精确安装（包含 FastAPI, Uvicorn, Shapely 2.1, ezdxf 1.4, CairoSVG, Pillow, VTracer, Pydantic 等）
- **前端运行环境**：
  - **Node.js 运行时**：Node.js 18.0+ 或 20.0+ (LTS)
  - **前端包管理器**：npm 9.0+ 或 pnpm
  - **前端依赖**：通过 `frontend/package-lock.json` 精确安装（包含 Vue 3, Three.js, Vite, TypeScript, TailwindCSS 等）

具体表现为：

2. **三维纹样星球与图谱漫游**：744 个文化实体节点的三维力导向与自转漫游完全由 WebGL / Three.js 纯数学程序化模型实时驱动；

5. **活态共创工坊**：自由画笔、多向极坐标对称变换与当代资产不可变谱系入库完全在本地客户端与 SQLite 数据库中完成；

## 二、 模式一：Docker Compose 源码构建运行（赛事方首选）

这是最推荐的复现方式。通过 Docker 容器化编排，避免污染评审宿主机环境，且排除了不同系统基础软件版本的偶发干扰。

### 2.1 步骤一：准备环境配置文件
在项目根目录下复制配置文件模板：
```bash
cp .env.example .env
```
用任意文本编辑器打开 `.env` 文件，确认核心参数：
```ini
# 设置管理接口访问密钥（用于打样管理与后台管理）
ADMIN_PASSWORD=judge-secure-pass-2026

# 设置对外暴露的访问端口（默认 8088；若本机 8088 被占用，可修改为 8098 或其他空闲端口）
PORT=8088

# 设置构建与运行架构（ARM64 填 1.3.0-arm64，x86_64/AMD64 填 1.3.0-amd64）
IMAGE_TAG=1.3.0-arm64
```

### 2.2 步骤二：源码一键构建并启动
执行标准 Docker Compose 编译构建指令：
```bash
docker compose up -d --build
```
> **说明**：系统将自动基于 `deploy/backend.Dockerfile`（安装 libcairo2 并锁定依赖）和 `deploy/frontend.Dockerfile`（Node 编译并集成 Nginx）完成镜像构建，并挂载独立的 `xiyu-data` 持久卷。

### 2.3 步骤三：服务健康检查
在终端中执行健康检查命令，验证 API 容器与知识库初始化状态：
```bash
curl http://localhost:8088/api/health
```
**预期输出**：
```json
{"status":"ok","patterns":60}
```
当返回状态为 `ok` 且 `patterns` 数量为 60 时，表明后端拓扑引擎与 60 篇纹样库已成功就绪！

### 2.4 步骤四：在浏览器中打开全系统
打开现代浏览器（Chrome / Edge / Safari / Firefox），访问：
```
http://localhost:8088
```
即可进入「锡语华纹」系统全景首页进行功能核验。

## 三、 模式二：本地物理机源码分端运行（深度代码审计）

如需对后端 Python 代码或前端 Vue 3 源码进行断点调试或代码审计，可按如下步骤分别启动前后端服务：

### 3.1 后端服务搭建与运行（FastAPI）
1. **安装系统图形依赖**：
   - *Ubuntu/Debian*：`sudo apt-get install -y libcairo2`
   - *macOS*：`brew install cairo`
2. **创建并激活 Python 3.11+ 虚拟环境**：
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```
3. **安装锁定依赖包**：
   ```bash
   pip install -r backend/requirements.lock
   ```
4. **启动后端异步 API 服务**：
   ```bash
   export DATA_DIR="./runtime"
   export ADMIN_PASSWORD="judge-secure-pass-2026"
   uvicorn backend.app:app --host 0.0.0.0 --port 8000 --reload
   ```
   后端服务启动后，可在浏览器访问交互式 API 接口文档：`http://localhost:8000/docs`。

### 3.2 前端服务搭建与运行（Vue 3 + Vite）
1. **进入前端目录**：
   ```bash
   cd frontend
   ```
2. **安装前端依赖包（按锁定文件安装）**：
   ```bash
   npm ci
   ```
3. **启动 Vite 本地开发服务器**：
   ```bash
   npm run dev
   ```
   > **说明**：Vite 会在本地启动开发服务器（通常为 `http://localhost:5173`），并通过配置的代理网关自动将所有以 `/api` 与 `/assets` 开头的请求转发到后端 8000 端口。

4. **前端生产打包校验**：
   ```bash
   npm run build
   ```
   控制台输出 `dist/` 静态产物无报错，表明前端 TypeScript 类型与模板校验 100% 通过。

### 3.3 原始学术资料全量解析验证（可选）
如需验证系统如何从原始 Word 文档解析生成知识库，可在项目根目录下执行全量文档 Ingest 解析流水线：
```bash
python -m backend.ingest 原始内容/数据 seed
```
系统将自动读取 `原始内容/数据` 目录下的 60 篇专业 Word 文档，执行正交校正、主体轮廓提取、SVG 矢量化与意象关系提取，生成 `seed/catalog.json` 与质量报告。

## 四、 模式三：预构建镜像极速免编译复现（评委极速通道）

项目在 `outputs/1.3.0/` 目录下为评审专家预先打包了开箱即用的 Docker 镜像，评审专家甚至**无需连接互联网下载任何编译包**，即可极速启动：

1. **导入对应架构的镜像包**：
   - Apple Silicon Mac（ARM64）：
     ```bash
     docker load -i outputs/1.3.0/xiyuhuawen-1.3.0-arm64.tar.gz
     ```
   - x86_64 / AMD64 PC / Linux 服务器：
     ```bash
     docker load -i outputs/1.3.0/xiyuhuawen-1.3.0-amd64.tar.gz
     ```
2. **初始化配置**：
   ```bash
   cp .env.example .env
   # 确认 IMAGE_TAG 与当前架构对应 (1.3.0-arm64 或 1.3.0-amd64)
   ```
3. **免构建一键拉起**：
   ```bash
   docker compose up -d --no-build
   ```

## 七、 常见问题排查与技术支持（FAQ）

### Q1：Docker 启动时提示端口 `8088` 冲突或已被占用？
**解决方案**：
在 `.env` 文件中修改 `PORT` 变量即可，例如改为 `8098`：
```ini
PORT=8098
```
随后重新执行 `docker compose up -d`，通过 `http://localhost:8098` 访问。

### Q2：本地源码运行后端时报错 `ImportError: cannot load library 'libcairo.so.2'`？
**原因分析**：
CairoSVG 依赖系统级的底层 C 库 `libcairo2` 进行矢量光栅化计算。
**解决方案**：
- Linux (Ubuntu/Debian)：`sudo apt-get install -y libcairo2`
- macOS：`brew install cairo`
- Windows：推荐直接使用 Docker 模式运行，容器内已预装全部底层 C 依赖。

### Q3：如何停止或重置系统？
- **安全停止服务**：`docker compose stop`
- **重启服务**：`docker compose restart`
- **彻底清理容器（保留持久化数据）**：`docker compose down`
- **重置所有业务数据（谨慎操作）**：`docker compose down -v`（将一并清空持久卷数据）。
