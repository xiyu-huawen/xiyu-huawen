# 新生杯参赛交付版 1.1

## 作品主张

以“可追溯的文化基因＋结构生成＋人的参与＋工艺文件”建立从纹样研究到当代器物设计的转化链路。不使用“国内首创”“已经量产”等未经验证的表述。

文化价值：每个调用图元保留文档、编码、图片版本、确认关系和几何操作。候选与同码冲突仍保留为待核对线索。

技术价值：基于几何算子而非自由生图完成可编辑纹面；直接确认的意象用于寓意推荐，图元的其他关联另行展示。三维、矢量和工程文件使用同一作品版本。

参与价值：用户决定祝愿、气质、器物与结构，可以改换辅助图元、绘制排列轨迹、比较版本。寓意锚点默认锁定；需要改变时必须主动解除。

落地价值：生成真实SVG、PNG、JSON和DXF沟通包，可提交打样需求并由管理员更新状态。未配置AI也可以完成核心流程。

## 三分钟演示建议

1. 首屏选“八方安宁”、气质与茶承；记录个人心意。
2. 探源：确认PAT-005八角外框与八方安宁的关系；说明确认关系与候选的区别。
3. 比较三个方向，选择“跨源相生”，观察客家四叶莲心与八角外框各自承担的结构。
4. 共创：框架锁定，替换主纹；展开进阶编辑调整节奏，或绘制辅助图元的排列轨迹。
5. 成器：拖动平面—入器进度，旋转观察；保存作品，下载DXF工程包并核对毫米尺寸。
6. 如需展示商业链路，提交一条明确标为测试的打样需求，再由后台更新状态。AI服务未配置时如实说明，不模拟生成画面。

## 可验证功能

- 全库744条来源节点，实例化渲染；全局纹样纹理使用256px缩略图，聚焦后读取原图。
- 60篇原始资料；145份矢量出现记录，141份独立SVG。没有合格矢量的样本仅浏览。
- 每轮评估24个参数候选，按三类结构方向选出结果；六种构图语法及真实布尔几何。
- 主纹、框架、环饰、点缀；锁定锚点、最近20步历史、会话恢复、作品收存。
- 七种器物：茶承、紫砂壶、书签、圆形首饰盒、花器、挂坠、茶罐盖。均为数字设计载体，不冒充已打样产品。
- 正形、负形、轮廓三种工艺视觉；材质与饰面切换、几何凸起、拆解及入器过渡。
- DXF以毫米制闭合折线表达轮廓与孔洞；参数记录画布尺寸、实际图案边界、校验结果和来源。
- 打样需求入库，后台状态包括待处理、沟通中、试制中、完成、退回；联系方式仅管理员列表返回。

## 商业验证路径

个人礼赠可验证个性表达与设计服务需求；机构礼赠可验证系列配方与小批量协作；美育研学可验证互动教学和作品输出。网站提供实际体验与交付工具，不虚构收入、用户量或生产订单。

项目计划书中记录的线下试运营销售与工坊合作，可作为已有基础介绍，但应与本网站的新流程、尚待验证的收入路径区别说明。
