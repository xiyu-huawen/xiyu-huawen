# 锡语华纹：从可解释的文化关系，到可度量的器物设计

本轮定位：一套把文化阅读、结构共创和工艺沟通放在同一工作流中的传统纹样工具。创新主张是人与文化资料的交互方式及交付闭环，不能宣称使用了独创大模型、获得工厂认证或已经实现规模化商业收入。

## 三个可现场操作的亮点

### 纹样星球：让知识成为可探索的空间

全库纹样、基因和意象构成三维关系网络。自动环游让观众先看到整体；点击、检索与关系高亮让用户追到具体来源；节点拖动用于调整阅读布局，不会改变资料或文化事实。与当前纹样有关的文章可直接打开，所选纹样或图元可以进入造物。

这不是把普通列表换成球体：阅读、来源核对和设计取材通过同一份真实资料连接，用户的选择会继续进入后面的作品。

### 因器而变：十二类器物与结构共创

茶承、紫砂壶、茶杯、茶叶罐、茶罐盖、花器、香插、笔筒、书签、圆盒、挂坠与案头摆牌均有本地程序化三维器型。用户可沿用当前纹样换器，观察曲面贴合、材质和金属层次，而不必重新开始。

主纹、框架、环饰与点缀具有独立角色。保留寓意锚点后，仍可探索镜像、连续、循迹、正形、负形与轮廓。手绘轨迹与版本对比让用户参与组织结构，而非只接收一张结果图。

### 工艺透视：把图案变成可以讨论的尺度

当前纹面按配方尺寸映射至毫米网格；双端标尺、坐标输入和放大视图可以量出任意两点间的距离。下载的工程包包含毫米制DXF闭合轮廓、原始SVG、尺寸参数与来源档案，便于与工坊讨论装饰范围和轮廓。

屏幕尺不是实体屏幕的一比一校准；手动测距不是自动最小线宽检测；曲面预览不等于曲面展开或工厂设备路径。这些边界应在答辩中说清楚。

## 建议展示顺序（约三分钟）

1. 打开纹样星球，观察自动环游，选中一份纹样，查看关系并拖动一个节点。
2. 打开与该纹样关联的知识文章，进入来源档案，再用该纹样造物。
3. 换成茶杯或笔筒，再换成香插，说明同一纹样如何遇到不同器面。
4. 改变一次结构或虚实关系，查看修改后的纹样，保留或撤销选择。
5. 在工艺透视器拖动标尺，观察毫米读数；下载DXF工程包，展示真实文件及来源。

## 真实价值与验证路径

- 礼赠设计：让需求从“想要一种祝福”变为可回看的配方、器物和尺寸，减少沟通歧义。
- 非遗教育：知识阅读、构图实验和自主操作可以生成可带走、可继续修改的作品。
- 工坊协作：统一来源、轮廓与参数资料，降低前期制版沟通成本。加工线宽、厚度、材料、连接和耐用性仍须实物打样。

后续价值应以研学完成率、设计修改次数、工程包使用反馈和实物打样结果来验证。没有这些数据前，不把潜在价值写成已经实现的市场成果。
