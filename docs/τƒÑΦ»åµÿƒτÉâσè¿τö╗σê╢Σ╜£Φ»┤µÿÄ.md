# 知识星球与核心动画制作说明

参考本机《AI星际学习地图》和系列 06.html：采用可交互轨道节点、可暂停的 SVG 分镜和时间轴，不采用背景视频替代功能。

## 三段核心演示

1. 纹样解构（8秒）：真实纹样原图 → 轮廓描边 → 中心、环带、点缀依次分离 → 悬停显示真实资料来源。各层必须使用现有 SVG，禁止生成虚构传统符号。
2. 祝福关联（6秒）：长寿意图节点 → 高亮资料确认的关联边 → 显示候选纹样缩略图；线条生长仅表达关联路径，不显示虚构概率。
3. 从纹到器（8秒）：二维纹样 → 排列调整 → 沿器物表面贴合 → 灯光掠过锡饰。保留暂停、逐步播放、减少动态效果模式。

## 如需外部生成素材

生成“深蓝空间中的银锡与铜金材质实验，柔和青色侧光，中央留空，无文字、无标识、无具体传统纹样”的 6 秒无缝背景。输出 1920×1080 WebM 和首帧 PNG。只用于知识页介绍区，不覆盖文字或画布。

知识星球应使用真实素材节点：拖到画布后由现有图元选择接口更新设计；移动端提供“应用”按钮。未确认寓意必须单独标记，不得通过动画包装为事实。
